Privacy Policy

Friendly Neighbour Assistant ("the app") is a personal tool used by one person, its owner. It has no other users.

What data the app accesses

Only with the owner's explicit consent, and only in read-only mode:

  • Google Calendar events (scope calendar.readonly);
  • Gmail messages (scope gmail.readonly);
  • Google Drive documents (scope drive.readonly).

The app never sends, modifies or deletes email, events or files.

How the data is used

The data is read on demand to answer the owner's own questions and to prepare a short daily summary for the owner. To generate those answers, the relevant text is processed by the Anthropic Claude API. The data is not used for advertising, profiling or any other purpose.

Storage and sharing

The app runs in the owner's private Google Cloud project. Google data is not stored beyond what is needed to answer a request. The data is not sold and not shared with anyone, other than processing by the Anthropic Claude API as described above.

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
